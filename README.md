## Установка пошагово

### Что нужно установить

| Программа | Версия | Ссылка |
|---|---|---|
| Python | 3.12 или новее | [Скачать](https://www.python.org/downloads/) |
| Node.js | 20 или новее | [Скачать](https://nodejs.org/) |
| Git | любая | [Скачать](https://git-scm.com/downloads) |

> **Важно.** При установке Python отметьте галочку **Add Python to PATH**.

Установите всё это до того, как переходить к командам ниже.

### Клонирование проекта

Откройте **PowerShell** и выполните:

```powershell
git clone https://github.com/orenfsp/orencode-texnolab.git
cd orencode-texnolab
```

### Запуск сервера

Сервер и сайт запускаются в двух разных окнах PowerShell. Начнём с сервера.

> **Важно.** Все команды сервера выполняйте из папки `backend`. Путь в начале строки PowerShell должен заканчиваться на `backend>`.

```powershell
cd backend

python -m venv .venv

.\.venv\Scripts\Activate.ps1
```

Если PowerShell пишет, что выполнение скриптов отключено, введите команду ниже, ответьте `Y` и повторите активацию:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

Дальше:

```powershell
python -m pip install --upgrade pip

pip install -r requirements.txt

python -m app.seed

python -m uvicorn app.main:app --port 8000
```

Команда `python -m app.seed` создаёт базу и заполняет её демо-данными. Не закрывайте это окно, пока работаете с платформой.

Описание API: http://127.0.0.1:8000/docs

### Запуск сайта

Откройте **второе окно** PowerShell, перейдите в папку проекта и выполните:

```powershell
cd frontend

npm install

npm run dev
```

Если PowerShell не даёт запустить `npm`, используйте `npm.cmd install` и `npm.cmd run dev`.

Готово. Платформа открывается по адресу http://localhost:5173

### Вход в систему

Войдите как `admin@fsp56.demo`, пароль `demo1234`.

## Запуск через Docker

Если установлен Docker Desktop, всё поднимается одной командой из корня проекта:

```powershell
docker compose up --build
```

Сайт будет на http://localhost:5173, API на http://localhost:8000/docs. При каждом запуске контейнера демо-данные создаются заново.

## Настройки

Ничего настраивать не нужно, всё работает сразу. Если нужно изменить настройки, создайте файл `backend/.env`:

```powershell
cd backend
copy .env.example .env
```

| Переменная | Что делает |
|---|---|
| `FSP_DATABASE_URL` | адрес базы. Без неё используется файл `backend/fsp.db`. Для PostgreSQL: `postgresql+psycopg://fsp:fsp@localhost:5432/fsp` |
| `FSP_JWT_SECRET` | секрет для входа. На рабочем сервере замените на длинную случайную строку |
| `FSP_PUBLIC_BASE_URL` | адрес сайта для ссылок в уведомлениях и QR-кодов |
| `FSP_ISSUER` | адрес сервера для входа через ФСП ID |
| `FSP_TELEGRAM_BOT_TOKEN` | токен Telegram-бота. Без него уведомления пишутся только в лог |

## Реализованные сценарии

Реализованы все 8 обязательных блоков и все 12 дополнительных сценариев (Д1-Д12).

Главный сценарий:
1. Федерация создаёт соревнование и открывает приём заявок.
2. Спортсмен или тренер подаёт заявку.
3. Федерация одобряет заявки, назначает судейскую коллегию и закрывает приём.
4. Федерация вносит баллы, платформа расставляет места и формирует протокол.
5. Протокол публикуется, результат попадает в историю спортсмена, все получают уведомления.

### Обязательные блоки

| № | Блок | Что реализовано и где посмотреть |
|---|---|---|
| 1 | Фронт в стилистике ФСП, адаптивный | Любые страницы на ПК и телефоне. Боковое меню превращается в выдвижное. Все маршруты проверены на ширине 375 px без горизонтальной прокрутки |
| 2 | Бэк-система | Swagger `/docs`, 57 таблиц, `docs/data-model.md` |
| 3 | Кабинеты, несколько ролей | `coach@`, `student@` > "Кабинет" в меню. Права по активной роли (`app/deps.py`): судья не может подать заявку за спортсмена |
| 4 | Календарь, заявки, коллегии, протоколы, история | Сквозной сценарий выше. Смешанный формат, ЕКП и региональный план с номером, положение (загрузка и скачивание), типы соревнований из справочника, модерация, коллегия с должностями, протокол со всеми участниками |
| 5 | Разряды и категории, контроль сроков, уведомления | Федерация > "Разряды" (заявки, кандидаты по ЕВСК, присвоенные с приказом и "за что получен") и "Судьи и категории". Спортсмен > "Результаты и разряд". Тренер > "Разряды подопечных". Блок "Сроки" в каждом кабинете. Напоминания за 30/7/1 день, Telegram |
| 6 | Реестр и динамика численности | "Реестр" с фильтрами (дисциплина, организация, разряд, возрастная группа, муниципалитет, этап); "Численность" - график, разрезы, выгрузка .xlsx |
| 7 | Рейтинг и сборная | "Рейтинг": расчёт по каждому, ×1,2, исключение дисквалифицированных, настройки баллов. "Сборная": состав по рейтингу, список и проект приказа |
| 8 | Документы по формам | Протокол (.xlsx/.docx), список сборной (.docx/.xlsx), проект приказа (.docx), отчёт о выступлениях спортсмена (.docx/.xlsx), численность (.xlsx), согласия ПДн (.docx) |
| - | Журнал действий, согласия ПДн | "Журнал действий". Согласия при регистрации (`/register`), для несовершеннолетних - от законного представителя; хранятся и скачиваются в профиле |

### Дополнительный функционал

| № | Сценарий | Что реализовано и где посмотреть |
|---|---|---|
| Д1 | ФСП ID (OpenID Connect) | http://localhost:8000/demo-client/ > "Войти через ФСП ID" > согласие > данные userinfo. Регистрация клиентов: "Интеграции и ФСП ID". Discovery: `/.well-known/openid-configuration` |
| Д2 | Интеграции | "Интеграции": токены с правами, вебхуки с подписью HMAC. Импорт результатов с автопротоколом: `examples/import_results.py`, описание - `docs/integrations.md` |
| Д3 | Организации, группы, журнал | Реестр > "Организации" > карточка (лицензия, программы). Тренер > "Группы и журнал": зачисление, перевод, журнал очно/онлайн с подтверждением. Данные идут в отчёт о численности (разрез "этапы") |
| Д4 | Нормативы и аттестация ФССП | "Нормативы ФССП" (включая скорость печати). Тренер > группа > "Внести норматив" (платформа сама сравнивает с порогом) > "Аттестовать". История - в "Мой путь" у спортсмена и у тренера |
| Д5 | Апелляции и нарушения | Спортсмен > "Апелляции" (с файлами). Федерация > "Апелляции и нарушения": решение с обоснованием корректирует протокол. Рапорт судьи > дисквалификация или техническое поражение |
| Д6 | Показатели развития | "Развитие вида спорта": динамика, организации, соревнования, источник у каждого показателя, подтверждающие документы |
| Д7 | Личный путь и справочник | Спортсмен > "Мой путь". Справочник понятий `/guide` |
| Д8 | Премии Губернатора | "Премии Губернатора": претенденты по протоколам, суммы по справочнику, ходатайство (подготовлено > направлено > назначено), пакет .docx, напоминание до 1 февраля |
| Д9 | Кабинет министерства | `ministry@` - только чтение |
| Д10 | Справка с QR-кодом | Спортсмен > "Результаты и разряд" > "Справка" > .docx с QR > публичная проверка `/verify/<код>` |
| Д11 | Навигатор для новичка | `/start` без входа: дисциплины, где заниматься, ближайшие старты, регистрация |
| Д12 | Документы о судействе | Карточка соревнования > "Справка о составе .docx". Судья > "Отчёт о судействе .docx/.xlsx" |

## Частые проблемы

| Проблема | Что делать |
|---|---|
| `python` не найден | переустановите Python и отметьте Add Python to PATH |
| Порт 8000 или 5173 занят | закройте программу, которая его использует |
| Сайт открылся, но данных нет | проверьте, что сервер запущен и открывается http://127.0.0.1:8000/docs |
| Не получается войти | выполните `python -m app.seed` и попробуйте снова |
| `pip install` идёт очень долго | перенесите проект из папки с синхронизацией (OneDrive) в обычную, например `C:\dev` |
